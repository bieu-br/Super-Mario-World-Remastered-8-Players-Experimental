Super Mario World Remastered — 8 Players Experimental

Feito por Bieu | Versão Experimental v0.1

⚠️ ATENÇÃO: ESTE PROJETO É EXPERIMENTAL!

Esta é uma modificação não oficial de Super Mario World Remastered, com o objetivo de expandir o modo cooperativo, adicionar personagens, experimentar novas mecânicas e melhorar a experiência multiplayer local.

Esta NÃO é uma versão estável ou finalizada.

O projeto está em desenvolvimento e pode apresentar muitos bugs, erros gráficos, animações incorretas, travamentos, incompatibilidades com controles e funcionalidades incompletas.

O objetivo é continuar atualizando e corrigindo os problemas conforme forem descobertos.

🎮 Principais novidades

Multiplayer local para até 8 jogadores

O projeto original foi expandido para permitir a seleção de até 8 jogadores locais.

Seleção de 1 a 8 jogadores.

Novos cursores para os jogadores P5, P6, P7 e P8.

Cores diferentes para identificar os jogadores.

Interface de seleção de personagens expandida.

Adaptações no HUD e nos menus para multiplayer.

Possibilidade de escolher personagens repetidos.

O multiplayer com 8 controles ainda precisa de testes completos.

🎮 Novo sistema de confirmação de controles

Cada jogador pode confirmar individualmente seu controle antes de iniciar a partida.

Cada jogador pressiona um botão no controle que deseja utilizar.

O sistema identifica e atribui os controles.

SELECT/BACK: permite atribuir um mesmo controle aos jogadores restantes.

ENTER: permite selecionar o teclado para o primeiro jogador.

O modo de controle compartilhado é experimental: os jogadores atribuídos ao mesmo controle recebem os mesmos comandos.

🔨 Nova habilidade especial — Martelada

Mario e Luigi receberam uma habilidade especial ativada pelo:

Triângulo (PlayStation) / Y (Xbox)

A habilidade utiliza animações de martelo adaptadas dos sprites existentes de Super Mario World.

Funcionalidades implementadas experimentalmente:

Sequência de sete quadros para a martelada.

Animações adaptadas para Mario e Luigi.

Variações visuais para as formas pequena, grande e alguns power-ups.

Ataque durante a movimentação.

Colisão ao longo do trajeto do martelo.

Possibilidade de atingir inimigos e interagir com blocos.

Efeito de impacto no chão, com partículas e dano em área.

Efeito sonoro de impacto.

Martelada desativada quando o personagem estiver montado no Yoshi.

Sem barra de cooldown adicional.

A colisão do martelo e suas interações com inimigos e blocos ainda podem apresentar bugs.

📦 Sistema de duas Item Boxes

O HUD foi modificado para experimentar um sistema com dois espaços de reserva.

Duas caixas de itens.

Ícones de itens ajustados.

Seleção da caixa ativa pelo analógico direito.

Movimento para a esquerda ou direita para alternar a seleção.

O sistema pode apresentar problemas de interface e compatibilidade com controles.

🎮 Como instalar e jogar

Baixe a versão para Windows na seção Releases do GitHub.

Execute o arquivo .exe do jogo.

Na primeira inicialização, o jogo solicitará uma ROM original de Super Mario World.

Coloque sua ROM, obtida legalmente, na pasta indicada na tela do jogo.

Renomeie o arquivo para baserom.sfc.

Volte ao jogo e pressione Enter no teclado ou A no controle para verificar a ROM.

Após a verificação, escolha a quantidade de jogadores e configure os controles.

⚠️ Importante sobre a ROM

O jogo não acompanha nenhuma ROM.

É necessário utilizar uma cópia legítima e compatível de Super Mario World.

A ROM precisa ter o nome exato baserom.sfc.

Coloque a ROM na pasta mostrada pelo jogo, não necessariamente na mesma pasta do executável.

ROMs incompatíveis serão rejeitadas pelo verificador.

Esse funcionamento segue o sistema de verificação do Super Mario World Remastered original.
